# whatsapp-archiver-app

Native Android app (Kotlin + Jetpack Compose, Arabic RTL UI) that archives selected WhatsApp chats from the local
end-to-end encrypted backup (`msgstore.db.crypt15`) and uploads them to Google Drive (`drive.file` scope) every night,
or saves them to a local folder. It is a GUI replacement for the Termux tool
[Modwahi/whatsapp-archiver](https://github.com/Modwahi/whatsapp-archiver), with byte-identical output.

**التوثيق الكامل بالعربي في [اقرأني.md](اقرأني.md)**: إعداد Google Cloud، التثبيت، الاستخدام، والإصدارات.

- `core/`: pure Kotlin/JVM port of the tool's logic (crypt15 streaming decrypt, defensive msgstore reader, naming,
  day files, state, runner), plus parity tests against fixtures generated by the Python tool (`tools/gen_fixtures.py`).
- `app/`: Compose UI, SAF (read-only WhatsApp folder), Google Drive REST, WorkManager scheduling, Keystore-encrypted key.
- `.github/workflows/build.yml`: tests, signed APK, SHA-1 output, and a GitHub Release on every `v*` tag.
